# Flex Living – House Renting Website

Modern, responsive house-renting platform built with React, Vite, and Tailwind CSS.

## Features

- Sticky responsive navbar with search and mobile menu
- Hero search with location / property type filters
- Property listings with reusable cards, favorites, and hover effects
- Advanced filters: location, type, price, bedrooms, amenities
- Property details with image gallery and booking form validation
- About, Contact, Login, and Sign Up pages with form validation

## Tech stack

- React.js + Vite
- Tailwind CSS v4
- React Router
- Lucide Icons

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Scripts

- `npm run dev` – start development server
- `npm run build` – production build
- `npm run preview` – preview production build
